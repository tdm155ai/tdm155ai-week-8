# TDM 155AI week 8: the app

A Next app that renders the Markdown in `content/` (its README is the home page; `content/a/b.md` is `/a/b`) (`lib/content.mjs`). `/docs` (`app/docs/`) shows `content/docs/` as a docs site with a sidebar (`app/components/DocsSidebar.jsx`). The header nav is Docs, Machine, Remix, mwRemix (`app/components/Chrome.jsx`). `/machine` (`app/machine/`) is the Interview machine at its simplest (record, transcribe, Markdown; two microphones); `/machine/multi` (`app/machine/multi/`) is the multi-mic version for 3–8 microphones, which captures natively with ffmpeg through `api/capture` because browsers stop at 2 channels and uses `machine/api/suggest` for follow-ups; `/remix` (`app/remix/`) is a self-contained copy of the simple machine for students to change; and `/mw-remix` (`app/mw-remix/`) is the worked example with an AI producer, whose prompts are in `app/mw-remix/prompts.mjs`, imported by its page and routes and shown on the page. Each has its own `api/transcribe` route (and `api/suggest` where there's an AI), which read keys from the repo's root `.env` through `lib/keys.mjs`. Every other file and folder renders through the catch-all `app/[...slug]/`; images beside a doc are served by `app/context-media/`, and a light `/print` renders any page. See the repo `README.md`.
